## In-App Updates

- Download signed updates from the Project card, with visible progress and verification before installation.
- Save open edits and confirm before updating. The app stops its managed FXServer and background services before the installer takes over and restarts the app.
- Refresh checks for a newer release without reopening the app. Database work and other active operations block installation until they finish.
- Release assets are cryptographically verified before the release is published. Invalid signatures, mismatched versions, and downgrades are rejected.

Users on 0.5.2 or earlier must install this release manually once to gain in-app updates. Updater signatures are separate from Windows code signing, so Windows SmartScreen warnings may still appear.

## FiveM Firewall

- Inspect inbound and outbound TCP/UDP game-port access in **FXServer > Diagnostics**.
- Read game ports from the selected profile's configuration or enter them manually.
- Confirm setup of missing rules with administrator approval requested by the app.
- Remove only this app's exact rules; external rules, default policies, database ports and txAdmin ports are left alone.
- Conflicting block rules and organization policies are reported for review, not overridden.

Host firewall status does not verify router forwarding or hosting-provider rules. Review the [firewall guide](https://github.com/zoxile/fxserver-installer/blob/v0.6.0/docs/firewall.md) for limitations.

## Compatibility

- This release is the Windows x64 application. Linux desktop and terminal development remains on `feature/linux-terminal-support` and is not merged into this release.
- App settings keep the same storage identity. Back up databases and server configuration independently before maintenance.
- Build-tool dependencies include current compatible security fixes.
