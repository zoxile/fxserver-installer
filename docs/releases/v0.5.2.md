# 0.5.2 Beta

This release includes artifact discovery fixes and new reviewed operations and diagnostics tools. It remains a beta: validate changes on a disposable server and keep independent backups.

## Artifact Fixes

- Legacy discovery reads the official Cfx download page's structured Recommended and Latest Windows lists. The old listing now redirects to a page whose visible default link exposed only build 35245 to the previous scraper.
- Builds remain sorted and deduplicated, with JG Scripts issue reports and explicit confirmation for known-issue or unverified builds. Only published official Windows URLs are accepted.
- Enhanced selects its first published build automatically and retries an initial failed lookup once. Loading and failures are visible; an official URL override remains usable if discovery fails.
- A dismissible notice explains that FiveM for GTAV Enhanced is in early access, may be unstable, and may have resource compatibility issues.

## New Tools

- Slow-query log analysis groups normalized queries and summarizes timing and examined rows without executing imported SQL.
- Saved queries support folders and typed value placeholders, with an explicit review before execution. Database Browser bookmarks restore table, filter, sort, and paging selections.
- Server Logs groups repeated warnings and errors with nearby context while retaining the existing raw log viewer.
- Resource dependency inspection shows missing declarations, cycles, providers, suggested startup order, and impact before disruptive actions.
- Guided profiler recording captures the managed local server, analyzes JSON in a worker, and compares two captures.
- Maintenance Plans reviews backups and queued resource updates, then coordinates shutdown, backup, updates, preflight, restart, and startup observation. Failures pause the sequence; no automatic restore or rollback is performed.
- Configuration saves review the exact diff and static validation results, with masked secrets, blocking errors, and acknowledged advisories.

See the [operations guide](https://github.com/zoxile/fxserver-installer/blob/v0.5.2/docs/operations-guide.md) for scope, safety limits, and recovery guidance.

## Validation And Limits

- Automated checks cover frontend logic, native safeguards, desktop/narrow browser workflows, and disposable MariaDB integration. Browser workflows use a mocked native backend.
- Live official catalog checks verify current Legacy and Enhanced discovery. No artifact is installed by those checks.
- Maintenance and guided profiler recording have not been tested end to end against a live FXServer. Static dependency and configuration checks cannot prove runtime compatibility.
- Enhanced remains early access. MariaDB installer, Windows Server, and real-world restore coverage retain the limits documented in previous beta releases.
- Existing upstream Rust dependency audit warnings remain. A passing audit is not a guarantee that software has no vulnerabilities.
- The Windows installer remains unsigned. Fully quit the app before updating.

Report reproducible issues with version **0.5.2 Beta**, your Windows version, steps, and redacted logs using the [issue templates](https://github.com/zoxile/fxserver-installer/issues/new/choose).
