# 0.5.0 Beta

This feature release remains a beta. Validate it with disposable servers and databases before using it for important data, and keep independent backups.

## Features

- FiveM Enhanced artifact downloads and executable support alongside Legacy. Editions use separate folders, with guarded archive extraction and replacement.
- txData discovery supports internal and sibling folders without replacing saved paths. Ambiguous layouts require an explicit selection, and server logs follow the selected profile.
- Database Browser adds database/table creation, table statistics, and single-table check, analyze, optimize, repair, empty, and drop actions. Mutations require reviewed SQL, exact confirmation, and short-lived, single-use previews; system schemas are protected.
- Read-only database inspection covers server status, variables, processes, character sets, engines, accounts, and visible grants.
- Queries & Files adds SQL error guidance and on-demand schema/collation inspection. Failed queries and files are not automatically rewritten or retried.
- Optional remembered database logins use Windows data protection per workspace. The default remains session-only; saved credentials are validated when the database panel opens and can be forgotten from the shared connection card.
- MariaDB installation offers supported LTS series and exact releases. Same-series update checks, preserved-data version checks, explicit authentication compatibility, and stricter service controls reduce accidental incompatible changes.
- Database client discovery is cached and metadata requests are batched. Client processes have bounded output, result sizes, and deadlines without replaying writes through another driver.

## Security And Compatibility

- Hardened generated user-management SQL for quoting and SQL modes, and reject unsupported privilege input before changing accounts.
- Reattaching preserved MariaDB data retains its existing accounts and passwords. A fresh-install password is not a password reset for an existing database directory.
- Installer downloads retain checksum and Authenticode validation. Privileged service actions request application elevation only when needed.
- Legacy artifacts, existing query helpers, row editing, and Queries & Files remain available.

## Validation Limits

- Automated validation covers native fixtures, frontend tests, strict Rust linting, and browser workflows with mocked desktop commands.
- Real, disposable MariaDB 12.2.2 tests covered metadata/row reads, database/table operations, stale-preview refusal, SQL diagnostics, user/password changes, quoting, SQL modes, and process timeout cleanup. Existing user databases and services were not modified.
- Official download metadata was checked. A MariaDB 11.4.13 MSI passed checksum and publisher verification without being executed.
- Actual MSI installation, upgrade, preserved-data reattachment, Windows Server behavior, and Enhanced FXServer startup with real resources/players still need broader live testing. Mocked installer progress is not an end-to-end installation test.
- Installers remain unsigned. Dependency audits found no blocking vulnerabilities; upstream maintenance and non-Windows advisories remain documented in the [Security Policy](https://github.com/zoxile/fxserver-installer/blob/v0.5.0/SECURITY.md). This is not a guarantee against unknown vulnerabilities.

Report reproducible issues with version **0.5.0 Beta**, your Windows version, steps, and redacted logs using the [issue templates](https://github.com/zoxile/fxserver-installer/issues/new/choose).
