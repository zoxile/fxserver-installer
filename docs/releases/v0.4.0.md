# 0.4.0 Beta

This version is a beta and is not fully tested on live servers or databases. Issues and breaking changes may occur. Keep independent backups and test changes in a disposable environment before using them on an important server.

## Changes

- Saved workspaces, background tasks, scheduled backups, and health monitoring while the app is open or in the tray.
- Optional installable Live Bridge with local pairing, actual resource states, player information, and restricted resource controls.
- Encrypted configuration history, guarded restores, and guided diagnostics.
- Official Windows artifact browser, including non-recommended builds with reported-issue warnings.
- Resource update previews, preserved configuration selections, snapshots, pins, and reviewed sequential update plans.
- Database browser, constrained row editing, CSV exports, and isolated backup restore tests.
- Private workspace cloning and migration with explicit file selection and secret exclusions.
- Bounded incident timeline and improved background-operation responsiveness.
- Linked-resource preflight support and a confirmed one-time Force start override.
- Release hardening, dependency advisory fixes, and explicit beta labeling.
- Protected MariaDB client credential files, remote TLS verification, and bounded interactive SQL execution.

Existing Live Bridge installations from earlier development builds must be reinstalled through the app for protocol 2. Stop the server, review the reinstall preview, then start it and reconnect.

## Validation Limits

Automated validation uses temporary filesystem fixtures, loopback test servers, and mocked desktop/database responses. It is not live production acceptance testing.

- Live MariaDB install/update/uninstall, database mutations, and restore/migration operations have not been validated on every supported Windows or Windows Server environment.
- The Live Bridge needs validation on a disposable FXServer with representative resources and players before relying on it operationally.
- Long-running server load, crash recovery, and installer upgrade/uninstall behavior still need broader manual testing.
- Junction fixtures run automatically. The separate Windows symbolic-link test requires Developer Mode or symbolic-link privilege and is otherwise ignored.
- Installers remain unsigned. Back up user data before installing this beta or reverting to an older app version.

Known upstream dependency maintenance warnings are described in the [Security Policy](https://github.com/zoxile/fxserver-installer/blob/v0.4.0/SECURITY.md). No audit can guarantee the absence of unknown vulnerabilities.
